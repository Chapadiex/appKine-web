Una clase es un evento grupal único sobre una oferta grupal, con su cupo. No genera un turno por persona: las inscripciones se hacen después, desde el detalle de la clase. Cada clase se programa por separado. El box se puede elegir; si no se elige y la oferta lo necesita, el sistema toma uno libre.
