Programar una clase

Una clase es un evento grupal unico sobre una oferta grupal, con su cupo. No genera un turno por persona: las inscripciones se hacen despues, desde el detalle de la clase. Cada clase se programa por separado; si la oferta necesita un box, el sistema elige uno libre.
